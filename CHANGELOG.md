# Changelog

All notable changes to the Kontado project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

See [documents/CHANGELOG.md](documents/CHANGELOG.md) for the detailed changelog.

## [0.2.6] - 2026-02-12
- Predicted bills feature (PREDICTED status, `/api/bills/predicted`)
- Balance snapshots for tracking account balances over time
- Credit card balance graph (`/api/analysis/credit-card-balances`)
- Projected category breakdown on dashboard

## [0.2.5] - 2026-01-13
- Tags on bills and vendors (string arrays, max 128 chars each)

## [0.2.4] - 2026-01-12
- Category management (create/edit/delete custom categories)
- Vendor addressLine2 field
- Bill delete functionality
- Enhanced budget prediction logic

## [0.2.3]
- Bill creation page with recurrence features
- Refactored BillEditForm component

## [0.2.2]
- Category pie chart on dashboard
- Phone number formatting for vendors

## [0.2.1]
- Notification center with real-time updates

## [0.2.0]
- Analysis tab (history, budget predictions, vendor trends)
- Invoice number field on bills
- Quick mark as paid
- Global vendor structure

## [0.1.0]
- Initial release with bill tracking, vendor management, authentication, real-time updates
